# Results — one folder per GPU type

Each subfolder is a complete, self-describing run on one GPU model:

| File | Contents |
|------|----------|
| `manifest.txt` | hardware + toolchain provenance (GPU, driver, CUDA, nvcc, Mojo, torch) |
| `run.txt` | raw console output of all three benchmarks |
| `timings.json` | structured numbers (median/std/price per path count) for plots + tables |

The folder name (`<slug>`) is derived automatically from the GPU name by
`scripts/run_benchmark.sh` (e.g. "NVIDIA RTX 6000 Ada Generation" -> `rtx6000ada`).

- `rtx6000ada/` — the run reported in the paper.
- `h100/`, `a100/`, `rtx4090/` — reserved slots; each holds a `PENDING.txt` until a
  real run on that hardware replaces it.
- `SUMMARY.md` — cross-GPU comparison table, regenerated by
  `python3 scripts/collect_results.py --table --out results/SUMMARY.md`.

To add a new GPU: run `scripts/run_benchmark.sh` on it (a new `results/<slug>/`
appears automatically), then regenerate `SUMMARY.md`.
